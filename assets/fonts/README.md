# Fonts

Both families are self-hosted (latin and latin-ext subsets, WOFF2) and used
under the SIL Open Font License 1.1. The licence texts are in this folder.

| Family         | Files                     | Licence                      | Source                                    |
| -------------- | ------------------------- | ---------------------------- | ----------------------------------------- |
| Archivo        | `archivo-normal-*.woff2`  | OFL 1.1 (`OFL-Archivo.txt`)  | https://github.com/Omnibus-Type/Archivo   |
| Source Serif 4 | `source-serif-4-*.woff2`  | OFL 1.1 (`OFL-SourceSerif4.txt`) | https://github.com/adobe-fonts/source-serif |

Icons on the site are hand-drawn inline SVG (no icon font or icon library).
